## 我在做什么

我关注的不是“AI 能不能生成一份结果”，而是它能不能进入真实业务流程，持续、稳定、可检查地把事情做完。

目前主要围绕四个方向：

- **AI 电商实战**：选品、竞品、主图、评价与运营流程。
- **数据分析**：从原始表格到可信结论与可交付报告。
- **Agent Skills**：把方法论沉淀成跨 Agent 可复用的 `SKILL.md`。
- **自动化协作**：飞书、RPA、内容生产与知识库工作流。
